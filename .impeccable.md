# Design Personality — vdua

## Reference anchor

overreacted.io (Dan Abramov's blog). What I want from it: warm minimalism, typography-first reading experience, content as the product. Not a clone — my palette and structure are different — but the *philosophy* of putting writing first.

## What I like

- Typography that carries the design without needing decoration
- Light backgrounds with warm, earthy tones
- Generous whitespace that lets content breathe
- Clean code blocks that feel native to the reading experience
- Simple navigation — the content IS the product

## What annoys me

- Generic SaaS-looking designs (gradients, glass cards, floating elements)
- Overly dark/moody themes that feel like a hacker terminal
- Cluttered layouts with sidebars, widgets, and ads
- Designs that feel like a corporate documentation site
- Bouncy animations and playful UI elements

## Rules to break

- "Blogs should have dark mode by default" — light mode is fine. This blog is primarily light.
- Serif body text on a dev blog — most use sans-serif; this one uses Lora.
- Earthy/sage palette for tech content — most tech blogs use blue, purple, or gray.

## Hard rules

- Content-first. No element should distract from reading.
- No hero images. The article title and first paragraph are the hero.
- Code blocks are first-class citizens — as important as prose.
- Light mode primary. Dark mode optional, not default.
- 65ch max line width. Non-negotiable for reading comfort.
